# Investigation numérique

Ce domaine présente des travaux d'analyse forensique des systèmes de fichiers. Le rapport étudie la dissimulation de données dans le slack space, puis leur récupération au cours d'une analyse.

**Notions étudiées :** slack space, blocs d'allocation, calcul d'offsets et récupération de données dissimulées.
