# Automatisation de l'administration

Cette série construit les bases de l'automatisation d'infrastructure : installation, inventaire des hôtes, configuration d'Ansible et exécution de playbooks. Les exercices présentent une administration reproductible des hôtes Linux.

**Outils et notions :** Ansible, YAML, Linux.
